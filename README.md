## 核心功能

- 自动整理 Codex 普通及归档对话、Git 提交和项目资产。
- 按日、周和项目总结“做了什么功能”，过滤停止服务、文件名等低价值过程。
- 管理每日、每周和项目任务，并在日历、甘特与报告中保持一致。
- 统计 Token、估算工时、项目投入和 Codex 剩余额度，托盘数字实时更新。
- 自动沉淀可照着执行的知识，生成科技选题与每日推理案例。
- 管理本地视频、合集、播放和发布资料，跟踪科技、推理与人性主题视频生产进度。
- 提供 TAPD 工作同步、Codex 完成提醒、PC/APP 完整对照矩阵和每周整体检查。
- 项目资产支持置顶、隐藏与恢复，并按最近更新时间展示。
- 提供 Git 分支切换、合并、更新、拉取、安全回退、提交历史和自动提交信息。

数据默认保存在本机 SQLite；程序不会自动上传原始 Codex 对话。工时明确标记为估算，项目提交、清理和环境修改均需人工确认。
